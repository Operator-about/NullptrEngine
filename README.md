**NullptrEngine** - движок для создания игр на Android. \
**ДВИЖОК БОЛЕЕ НЕ РАЗРАБАТЫВАЕТСЯ!**.

❗**Версии Android для работы с движком:** \
Минимальной версией Android для работы с движком, является версией: **Android 10**. \
Рекомендуемой версией Android для работы с движком, является версией: **Android 13**.

⚠️**Предупреждение! В зависимости от версии Android некоторые новые функции Vulkan не смогут работать. \
Из-за этого рекомендуется работать с движком начиная с версии Android 13 для получения всех новых функций Vulkan**.

⚙️**Техническая часть движка:** \
Движок разрабатывается: на **языке программирования C++** с использованием **графического API Vulkan**. \
Движок **НЕ РАБОТАЕТ** с OpenGL.

📄**Про разработку движка:** \
**NullptrEngine** будет заточен только под **3D графику**. \
Поддержка 2D графики пока не планируется.
